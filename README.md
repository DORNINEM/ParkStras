# Projet Flashcards et Quiz

Ce dépôt contient divers outils interactifs pour l'apprentissage sous forme de flashcards et de quiz.

## Fichiers HTML

- **flashcards-ultra-v1.html** - Version 1 de l'application de flashcards ultra
- **flashcards-ultra-v2.html** - Version 2 de l'application de flashcards ultra
- **flashcards-ultra-v3.html** - Version 3 de l'application de flashcards ultra
- **galaxy.html** - Application interactive sur le thème de la galaxie
- **index.html** - Page d'accueil principale
- **parkstras-gemini.html** - Application spéciale Parkstras avec Gemini
- **pipotron.html** - Outil de génération automatique de texte
- **quiz-compact.html** - Version compacte de l'application de quiz
- **quiz.html** - Application de quiz standard
- **space.html** - Application interactive sur le thème spatial
- **sun-position-app-CLAUDE.html** - Application de position du soleil utilisant Claude
- **sun-position-app-CLAUDEV2.html** - Application de position du soleil utilisant Claude v2
- **sun-position-app-OPENAI.html** - Application de position du soleil utilisant OpenAI
- **sun-position-app-OPENAIV2.html** - Application de position du soleil utilisant OpenAI v2

## Fichiers JSON (Flashcards)

- **FC_Materiel.json** - Flashcards sur le matériel
- **FC_Offre.json** - Flashcards sur les offres
- **QZ_ALARME.json** - Questions sur les alarmes
- **QZ_Alarmes.json** - Questions sur les alarmes (version alternative)
- **QZ_General.json** - Questions générales
- **QZ_MANUEL.json** - Questions manuelles

## Ressources

- **logo-homiris.png** - Logo de l'application Homiris

## Description

Ces applications sont conçues pour faciliter l'apprentissage par la répétition espacée et les tests interactifs. Elles permettent de créer des expériences d'apprentissage engageantes à partir de fichiers JSON contenant des questions et réponses.
